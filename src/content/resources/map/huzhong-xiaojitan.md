湖中小祭坛是一份 Java 版建筑作品，作者把一整座哥特式祭坛搬到了湖心的一小块陆地上。建筑通体以白色石砌为主，靠密集的尖塔、飞扶壁与尖拱窗把视觉重心不断向上提；脚下的湖面则铺满睡莲与荷叶，冷硬的石作与柔软的花叶在同一张画面里对峙，让整座祭坛呈现出一种安静的仪式感。

主体可以拆成前庭、环形柱廊与祭堂三段来看。祭堂正面开两扇高而窄的尖拱窗，窗棂用镂空石砖做出网状分割；屋脊与四角立着数根细长的螺旋尖塔，顶端收成十字形。祭堂外侧是一圈连续拱券围出的环形柱廊，拱脚落在方柱上，使建筑在半空多出一层可以环行的平台。最外侧的前庭则用苔藓斑驳的残破石墙与散落的石堆围合，看起来像被湖水侵蚀多年的遗迹，与祭堂的精工细作形成新旧对照；一条石板长阶从湖岸通向祭坛，作为整组建筑的入口轴线。
