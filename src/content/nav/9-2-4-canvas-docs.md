Canvas 是一个为 Minecraft Fabric 模组生态系统设计的高性能渲染库。它并非一个普通玩家会直接使用的模组，而是一个**供其他模组开发者使用的 API 库**。它提供了一套远比原版游戏更强大、更灵活的工具，让开发者可以高效地渲染复杂的 3D 模型、自定义的方块/流体视觉效果以及各种高级的图形特效。

### 发展历程

Canvas 被认为是 Fabric 早期内置的渲染 API **Indigo** 的“精神继承者”。随着 Minecraft 渲染机制的日益复杂，社区需要一个更现代化、功能更强大且独立于 Fabric API 本身的渲染解决方案。因此，由 VRAM Guild（一个专注于图形学的开发者小组）牵头开发的 Canvas 项目应运而生。这份维基则是所有希望利用 Canvas 强大渲染能力的模组开发者，所必须学习和参考的官方文档。

### 社区生态位

Canvas 在 Minecraft 社区中扮演着“**Fabric 生态的图形渲染引擎**”和“**视觉类模组的基石**”这一关键角色。
1.  **赋能模组作者**：它是那些希望突破原版渲染限制的模组作者的利器。无论是想制作一个拥有复杂动画的机器，还是想实现一种独特的液体流动效果，Canvas 都提供了实现这些想法所必需的底层 API。
2.  **专业化的基础设施**：它将复杂的渲染管线管理、模型数据处理和性能优化等工作，封装成了一套易于使用的 API。这让模组开发者可以专注于实现自己的创意，而无需从零开始“造轮子”，去和底层的 OpenGL 直接打交道。
3.  **性能与扩展性的代表**：作为 Indigo 的继任者，Canvas 从设计之初就将高性能和高扩展性作为核心目标，是支撑起 Fabric 社区中许多视觉效果酷炫、模型精细的模组的重要技术基础。
