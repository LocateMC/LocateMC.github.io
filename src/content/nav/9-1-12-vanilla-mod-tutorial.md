《Minecraft 原版模组入门教程》（VanillaModTutorial）是一份由 zhangshenxing 整理、托管于 GitHub Pages 的**简体中文「原版模组」系统教程**（页面署名 ruhuasiyu，最后更新于 2022 年）。这里的"原版模组"特指**在不加载 Forge / Fabric 等 Mod Loader 的前提下**，仅通过命令方块、数据包（Data Pack）与资源包（Resource Pack）对游戏可玩性做出修改的做法——以此与使用 Java API 开发的 Mod 相区分。教程面向 Minecraft Java 版 1.13–1.19（重点 1.19），用大量中文图文把"如何不碰游戏本体就做出新物品、方块、机器与世界"讲透。

### 内容板块
教程分「理论篇」与「实践篇」，结构完整：
- **理论篇 · 数据包**：元信息与命名空间、函数、进度、战利品表（含谓词、物品修饰器）、配方（合成/烧炼/锻造台等）、结构、标签、维度与维度类型、自定义世界生成（噪声/生物群系/地物/结构地物/模板池等）。
- **理论篇 · 资源包**：语言文件、自定义物品模型、纹理、音效、字体、着色器（后处理/核心）。
- **理论篇 · 基础**：命令基础、工具准备（编辑器/NBT 编辑器/绘图工具）、游戏文件夹结构、JSON 格式。
- **实践篇 · 设计**：物品设计（右键交互/食物/药水/盔甲/工具武器）、方块设计（视线追踪/交点计算/命令方块替换）、机器设计（GUI/配方/容器/管道）。
- **实践篇 · 进阶**：NBT 合成与烧炼、植物（作物/树）、物品与实体处理（背包/耐久/红石/交易/连锁）、算法（随机数/世界生成结构/维度探测/位运算与种子）。

### 教程特点
在中文 Minecraft 创作教学生态里，这份教程占据「**纯原版（数据包 + 资源包）创作的系统入门**」这一独特位置。它与 Fabric/Forge 等 Java 模组教程形成互补：当玩家想为原版服务器、或不想装 Mod Loader 的环境添加新内容时，本教程提供了一条"零代码依赖、随版本迁移成本低"的路径。虽然其核心是数据包 / 资源包而非 Java 字节码修改，但对于想理解 Minecraft 原版机制、进而迈向 Java 模组开发的初学者，它也是打牢底层认知的优质起点。
