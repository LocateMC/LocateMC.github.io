Mojira 是 Mojang Studios 官方运营的缺陷追踪器，基于 Atlassian Jira 搭建。它是玩家向官方反馈游戏问题的唯一正式渠道——你可以在这里检索既有的漏洞、提交新的 Bug 报告、对受影响的问题投票，或参与讨论以推动官方修复。需要注意的是，Mojira 仅用于缺陷报告，不承接客服求助、玩法咨询或新功能建议；提交前请先搜索是否已有相同报告，安全漏洞或利用手段则应创建仅自己与 Mojang 可见的私有报告。

它按游戏分设多个独立项目，提交前请先选对对应版本：

- **MC / MCPE** — Minecraft：Java 版（PC）与基岩版（Win10 / 主机 / 移动 / VR）
- **REALMS / MCL** — Minecraft Realms 租赁服与 Minecraft Launcher 启动器
- **BDS / WEB** — Bedrock Dedicated Server 基岩版官方服务端与 Mojang Web Services 网络服务

提交时也有几条约定：一份报告只报一个问题，便于官方跟进与管理；标题简明扼要，避免“求助！！！”这类无意义概括；描述中写清问题现象与可复现步骤，方便定位；创建前先搜索，避免重复，若已存在则直接在对应报告下参与讨论；发现漏洞或安全隐患时创建私有报告，仅自己与 Mojang 可见。
