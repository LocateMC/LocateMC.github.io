BDS（Bedrock Dedicated Server）是微软官方发布的基岩版专用服务器程序，支持 Windows 与 Linux 平台，是搭建原版基岩版服务器的最直接选择。

### 特点

- **官方出品**：与游戏版本同步更新，保证原版体验
- **跨平台**：提供 Windows 与 Linux 版本
- **可扩展**：可通过 LeviLamina 等加载器扩展插件支持
