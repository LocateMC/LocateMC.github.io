Endstone 是一款用 Python 语言编写的基岩版服务器软件，其核心目标是在 Python 中重新实现 Bukkit API，使 Java 版生态中成熟的插件有望运行在基岩版服务器上。

### 特点

- **Python 开发**：面向 Python 开发者开放服务端生态
- **Bukkit 兼容愿景**：旨在打通 Java 版与基岩版插件壁垒
- **开源项目**：活跃的 GitHub 开发

官方网站：https://endstone.dev/
