Fabric Wiki 是轻量级 Minecraft 模组加载器 Fabric 的官方文档中心和开发者社区维基。它为所有希望使用 Fabric 创建模组的开发者，提供了一套完整、权威的技术文档和教程，内容涵盖从设置开发环境、创建第一个模组，到深入理解 Fabric API、Mixin、游戏映射等高级主题。

Fabric 项目诞生于 Minecraft 1.13 版本之后，旨在提供一个比传统加载器更轻量、更新速度更快的模组开发平台；伴随着 Fabric 工具链的诞生，官方维基也同步建立起来。它由 Fabric 开发者和核心社区成员共同维护，随着游戏版本的迭代和 Fabric API 的不断扩充而持续更新，并迅速成为 Fabric 模组开发领域最核心、最可靠的知识来源。

因此，它在这一生态中的角色无可替代：官方维基被看作 Fabric 模组开发的唯一权威来源。与论坛、博客或视频教程中可能过时或不准确的信息不同，这里的内容由项目核心成员维护，始终最准确也最新；无论是配置开发环境、学习 API 用法，还是理解 Fabric 独特的工作原理，它都是开发者整个开发周期中必须反复查阅的手册与教科书。

它还定义了 Fabric 模组开发的最佳实践和标准流程，为整个生态的健康、有序发展提供了坚实基础——所有高质量的 Fabric 模组，背后都有遵循这份维基指导的开发实践。对刚入门的人，它是最好的起点；对已经上手的人，它则是长期备查的规范。
