PaperMC Documentation 是广受欢迎的高性能 Minecraft 服务器软件 Paper（一个 Spigot 的分支）的官方技术文档网站。它是一个综合性的知识库，服务于两大核心用户群体：服务器管理员和插件开发者——对前者，它提供详尽的服务器配置、优化和管理指南；对后者，它提供 Paper 独有 API 的开发教程和参考。

Paper 最初源于一个名为 PaperSpigot 的项目，其目标是集合各种性能优化补丁，以解决原版和 Spigot 服务器在大型社区中普遍存在的性能瓶颈。随着项目的不断发展，它逐渐从一个「补丁集」演变成了一个拥有自己独立 API 和开发团队的、更完善的分支 (Fork)，并最终更名为 Paper；这个官方文档站点的建立，标志着 Paper 项目的成熟，它取代了过去散落在论坛和 GitHub 上的零散信息，为整个社区提供了一个统一的、权威的知识来源。

它如今是高性能服务器的事实标准与官方手册，分量主要体现在三处。

- **性能的标杆**：对绝大多数追求高性能、高稳定性的公开服务器（尤其是拥有大量玩家的服务器）来说，使用 Paper 或其分支（如 Purpur）已成为业界的「黄金标准」，而这份文档就是配置和驾驭这一平台的官方说明书。
- **Bukkit/Spigot API 的超集**：Paper 在兼容所有 Spigot 插件的基础上，提供了大量独有的、性能更优或功能更强大的 API，这份文档是插件开发者学习和利用这些高级 API、编写更高质量插件的权威指南。
- **管理员与开发者的共同语言**：管理员通过它理解服务器的各项性能开关，开发者通过它编写能与这些配置良好协作的插件，两者共同保证了服务器生态的健康与高效。
