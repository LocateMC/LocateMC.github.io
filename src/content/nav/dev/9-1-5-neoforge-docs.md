NeoForge 文档是现代化 Minecraft 模组平台 NeoForge 的官方技术文档网站。NeoForge 是从著名的 Minecraft Forge 项目中分支 (fork) 出来的一个全新项目，旨在解决原 Forge 中长期存在的历史遗留问题、技术债和开发流程瓶颈；这份文档则为所有希望在新平台上进行模组开发的开发者，提供从入门到精通的最权威教程和参考。

NeoForge 项目诞生于 Minecraft 1.20 版本时期，由一群经验丰富的 Forge 社区开发者共同发起，他们希望通过一次彻底的重构，创建一个更稳定、更易于维护、对开发者更友好的模组平台。这个全新的文档站与 NeoForge 项目一同诞生，目标是吸取过往的教训，从一开始就为开发者提供一份结构清晰、内容准确、与平台本身紧密同步的高质量文档。

它代表着一个新时代的开端，也是现代化 Forge 生态的基石。一方面，它不是 Forge 文档的简单复制或改进，而是伴随着大量底层重构和 API 变动进行的全新编写，为愿意拥抱变化的开发者指明了新的方向；另一方面，对选择跟随 NeoForge 路线的开发者来说，它是唯一且最权威的参考，详细阐述了新的 API 设计、数据生成系统以及推荐的最佳实践，同时也为希望把原有 Forge 模组迁移过来的开发者提供了必要指导，是连接旧生态与新生态最重要的桥梁。

对新项目而言，它是省事的起点；对迁移者而言，先读它再动手，能少走很多弯路。
