Sponge Documentation 是 Sponge 服务器平台的官方技术文档网站。Sponge 是一个与 Bukkit/Spigot/Paper 生态完全不同的服务器插件 API，旨在提供一个更现代化、更健壮、设计上更优雅的插件开发框架，并且拥有一个独特的实现版本——SpongeForge，可以直接作为模组运行在 Minecraft Forge 服务器上，实现插件与模组的无缝共存。

Sponge 项目同样诞生于 Bukkit 项目停止更新之后的混乱时期。但与选择直接继承 Bukkit API 的 Spigot 不同，Sponge 的开发者们决定从零开始，设计一个全新的、他们认为更优秀的 API，希望解决 Bukkit API 中一些长期存在的设计缺陷，并原生支持与 Forge 模组的互操作性。这份官方文档，就是所有希望在 Sponge 这个全新体系下进行开发的服主和开发者的权威指南。

它代表了服务器 API 的另一条技术演化路径，也是模组与插件的融合者。

- **与 Bukkit 分道扬镳**：它不兼容 Bukkit 插件，但提供了更严格的类型安全、更清晰的服务架构和更强大的数据 API，选择 Sponge，就是选择了一套全新的、更现代的开发范式。
- **插件与模组的桥梁**：其最重要的特性是通过 SpongeForge 实现与 Forge 模组的原生兼容，这让服务器主可以在享受 Forge 丰富模组生态的同时，还能使用 Sponge 插件进行服务器管理和功能扩展，这是 Spigot/Paper 难以做到的。
- **开发者的「学院派」选择**：相比 Bukkit API 的「实用主义」，Sponge API 的设计更具「学院派」风格，更强调软件工程的最佳实践，因此吸引了许多追求代码质量和项目可维护性的开发者。
