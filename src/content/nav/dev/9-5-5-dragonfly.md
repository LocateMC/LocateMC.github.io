Dragonfly 是一个完全用现代编程语言 Go 为 Minecraft 基岩版 (Bedrock Edition) 从零开始编写的服务器软件。它并非基于任何现有代码的分支，而是一个全新的、独立的实现；其核心设计目标是追求极致的性能和简洁性，旨在充分利用 Go 语言在并发处理和开发效率上的巨大优势。

该项目的诞生，代表了基岩版服务器开发领域一次全新的技术路线探索。开发者选择 Go 语言，是为了从根本上解决传统服务器软件在多核处理器上性能伸缩性不佳的问题，并为开发者提供一个比 C++ 更简单、比 Java 更高效的开发体验；作为一个从头开始的开源项目，它致力于通过现代化的架构和简洁的代码，来吸引新一代的开发者加入，共同构建一个面向未来的、高性能的基岩版服务器。

它的生态位极其独特：既是 Go 语言生态的先锋，也是性能与现代化的新探索者。

- **全新的技术栈**：在基岩版服务器领域，已经有了 C++（官方 BDS）、Java（Nukkit）、Python（Endstone）等多种实现，Dragonfly 的出现则为社区带来了 Go 语言这一强大的新选择，为广大的 Go 开发者打开了进入 Minecraft 服务器开发的大门。
- **为性能而生**：Go 语言天生为并发而设计，Dragonfly 旨在利用这一特性，来构建一个能够轻松处理大量玩家和复杂游戏逻辑的高性能服务器核心，是探索 Minecraft 服务器性能极限的一次全新尝试。
- **独立的生态系统**：与 Nukkit 类似，它是一个完全独立的实现，拥有自己的插件 API；这意味着它不依赖于官方程序，但也需要从零开始构建自己的插件生态，吸引的是那些认同 Go 语言哲学、并愿意投身于一个全新生态系统建设的、具有前瞻性的开发者。
