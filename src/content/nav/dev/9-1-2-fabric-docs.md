Fabric Documentation 是 Fabric 模组加载器和其工具链（如 Loom）的官方技术文档网站。与社区驱动的维基不同，它提供的资源由 Fabric 官方维护，更加结构化和系统化，内容被清晰地划分为教程、核心概念、API 说明、工具链详解等模块，为开发者铺出一条从零开始的清晰学习路径。

该文档站点的建立，标志着 Fabric 项目在专业化和成熟度上的一个重要里程碑：当一个开源项目发展到一定规模时，仅有社区维护的维基是不够的，还需要一份由核心团队编写和背书的、更具权威性和结构性的官方文档。它由此成为 Fabric 工具链不可分割的一部分，与工具本身同步更新，确保信息的准确性和时效性。

如果说 Fabric Wiki 是一个自由、开放的社区知识库，那么 Fabric Docs 就是一本严谨、权威的官方教科书，两者的差别主要体现在三点。

- **结构化的学习路径**：为新开发者提供一条从「安装」到「发布」的、官方推荐的学习路线，避免在海量维基条目中迷失方向。
- **核心概念的权威解释**：对 Mappings、Mixins、Entrypoints 等核心设计理念以及官方工具 Loom 的工作原理，给出最深入、最权威的解释。
- **与维基互补**：官方文档负责定义「是什么」和「应该怎么做」，维基则承载「可以怎么做」和「遇到问题怎么办」，两者共同构成 Fabric 完整、健康的开发者学习生态。

因此，新手适合按官方的路径线性学下去，老手则常在动手写代码时回来核对核心概念与 API 说明。
