Pumpkin 是完全使用 Rust 从零编写的高性能 Minecraft 服务器软件，支持最新 Java 版协议（基岩版支持开发中），以多线程架构和高效内存管理著称，目标「赋能每个人托管快速高效的 MC 服务器」。

### 特点

- **极致性能**：多线程区块加载/保存（Vanilla/Linear/Pump 三种模式），安全优先
- **不兼容现有插件**：不支持 Bukkit/Paper 插件与 Forge/Fabric 模组，自带 WIT（WebAssembly）插件 API
- **高度可配置**：TOML 配置，可按需禁用功能；活跃开发中（重度开发阶段）
