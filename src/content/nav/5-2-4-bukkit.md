Bukkit 是定义 Minecraft Java 版服务端插件 API 的开源项目，虽然官方服务端已停止发布新版本，但其 API 设计深刻影响了 Spigot、Paper 等后续所有主流核心，是插件生态的事实标准基础。

### 特点

- **API 标准**：绝大多数服务端插件基于 Bukkit API 开发
- **历史意义**：CraftBukkit/Spigot/Paper 一脉相承的源头
- **Wiki 齐全**：SpigotMC 上保留着完善的 Bukkit 插件开发资料
