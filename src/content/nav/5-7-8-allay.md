Allay 是使用 Java 21 从零编写的基岩版（Bedrock Edition）服务器软件，主打可靠、快速与功能丰富，支持多版本架构（含网易版 1.21.90 ~ 国际版 1.26.44），并构建了 JVM 语言插件生态。

### 特点

- **多版本架构**：一次部署兼容多个基岩协议版本，减少玩家版本流失
- **JVM 插件**：支持 Java/Kotlin/Scala 插件，Gradle 模板开箱即用
- **工程完善**：AllayLauncher 启动器 + Docker 部署 + 高测试覆盖率
