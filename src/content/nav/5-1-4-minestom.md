Minestom 是一个开源的 Minecraft 服务器开发库（Library），不含任何 Mojang 代码，也默认不带生物 AI、合成、红石等游戏逻辑——开发者通过完整的现代 API 自行实现所需功能，常用于打造小游戏、空岛等高度定制化服务器。

### 特点

- **从零构建**：非即用服务端，集成进 Java 项目后按需开发
- **Instance 体系**：轻量的区块/实体集合模型，可随时创建、复制与传送
- **高性能多线程**：不兼容 Bukkit/Forge/Sponge 插件，适合技术型开发团队
