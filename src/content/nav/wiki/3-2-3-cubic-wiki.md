Cubic Wiki（原项目名 NitWikit）是一个由中文 Minecraft 社区共建的、以“从零开始手把手教你搭建和运营 MC 服务器”为核心目标的开服运维百科。站点自述为「一群笨蛋编写的 Minecraft 开服教程」，这种自嘲语气也折射出它面向的玩家定位：不是面向资深运维的硬核文档，而是面向想“自己开一台服务器试试”的普通玩家与新手服主。它由社区组织 Cubic Project 维护，源码同步公开在 GitHub，以开放协作的方式持续更新。

站点采用现代 Astro Starlight 文档站形态，按目标版本分四条主线：

- **Java 版**：高版本 Java 版服务器的搭建与运营，覆盖从版本选择、核心配置到插件 / 模组兼容的常见问题。
- **基岩版**：基岩版专属服务器教程（Bedrock Dedicated Server、Bedrock 互通等）。
- **通用**：跨版本通用的网络、安全、性能与运维经验。
- **关于**：项目说明与贡献指引。

整个站点首页除主结构外还展示了 50+ 位 GitHub 贡献者，提交、Issue 与 PR 共同构成迭代节奏——它是一份“活文档”，问题反馈、补丁、教程补充都直接进入仓库。在中文 MC 社区里，它占据着“开服教学”这一垂直生态位：与关注“装什么 mod / 玩什么整合包”的玩家向社区不同，它把镜头对准“如何让一台服务器稳定、安全、可维护地长期跑起来”这一上游问题；对刚准备踏入服主圈、需要一份从选购主机到日常运维一站式中文指引的用户来说，它是最贴近玩家语境的起步与进阶参考，能少走许多“能跑起来但说不清为什么”的弯路。同时，作为开源项目，任何玩家都可参与纠错与扩展，它与 MCBBS、贴吧问答形成互补，共同沉淀长期可用的知识库，也让中文玩家有了可以长期依赖的开服参考。
