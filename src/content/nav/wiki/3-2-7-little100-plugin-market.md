「开服手册」是 MC 插件市场（Little_100）站内的一份结构完整的中文开服文档集：从装 Java 到选服务端核心、配 `server.properties`、配权限插件、打通公网，再讲到日常运维与安全防护，70 余篇文档按"新手照着做就能开起来"的顺序编排。同一个站点里还有一份从 Spigot、Hangar、Modrinth 三大平台聚合而来的插件库（支持按功能分类、服务端类型、下载量筛选与排序，并可调用 AI 搜索与中文翻译），看完教程可以直接在旁边把插件找齐。

### 文档板块
文档按开服流程分块，每块都是一个独立的小专题：
- **Java 环境**：MC 版本与 Java 版本对应表（1.20.5+ 需 Java 21）、Temurin / Corretto / Zulu / GraalVM / Oracle JDK 各发行版对比与 Windows 安装步骤、JVM 启动参数调优。
- **服务端核心**：先有《服务端选择指南》说明怎么挑，再逐个介绍插件端（Paper、Spigot、Purpur、Folia、Pufferfish、Leaves）、模组端（Forge、NeoForge、Fabric、Quilt）、混合端（Mohist、CatServer、Arclight、Banner）、代理端（BungeeCord、Velocity）与跨平台（Geyser）。
- **服务器配置**：权限管理、世界管理、性能优化，外加对 `server.properties`、`bukkit.yml`、`spigot.yml`、`paper.yml`、`purpur.yml` **逐文件逐项**的中文注释解读（每个配置文件都拆出"概述 / 世界设置 / 性能优化 / 消息与外观"等多个页面）。
- **网络配置**：概述与前置知识、IPv4 与 IPv6 公网开服、云服务器开服、域名绑定与安全、FRP 内网穿透、P2P 联机。
- **运维管理**：Linux 与 Windows 运维、备份与恢复、安全防护。
- **插件与模组**：插件推荐、反作弊方案、模组推荐，以及常见问题 FAQ。

### 插件聚合与 AI 能力
插件库直接对接各平台公开接口拉取数据，筛选维度包括功能分类（经济、领地、传送、聊天、管理工具、小游戏等 15 类）、服务端类型与最低下载量，排序支持最热门 / 最新 / 最近更新 / 下载量 / 评分。站内 AI 有三条用法：搜索插件（按需求自然语言找，而非只给文字建议）、把英文插件名称与简介翻译成中文，以及在文档侧"阅读开服手册中的文档"后回答问题。另有「指导开服」页提供三种预设：上传服务器配置文件自动汉化注释、AI 从零引导搭建服务器、以及只读本地服务器文件做诊断的 Agent 模式（需 Tauri 桌面端）。

### 生态位
中文 MC 开服资料长期以论坛帖、视频和零散博客为主，往往是"能跑起来但说不清为什么"。这个站的价值在于把**选型—安装—配置—联网—运维**串成一条可检索的文档链，并且把最容易让人放弃的配置文件解读做成了体系；插件市场与文档放在同一站内，也让"看完教程顺手把插件装上"成为一条闭环路径，对准备自己开一台 Java 版服务器的新手尤其友好。
