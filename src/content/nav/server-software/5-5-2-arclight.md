Arclight 是基于 Forge 的混合服务端实现，致力于在较新的游戏版本上同时运行 Bukkit 插件与 Forge 模组，以活跃的版本跟进与社区支持著称。

它最突出的场景是「新版本 + 混合玩法」：对高版本 Forge 与插件组合的支持相对到位；作为国产项目，中文文档与社区支持比较完善；开发在 GitHub 上进行，迭代活跃、反馈响应也快。

如果服务器想跑较新的游戏版本，又同时需要模组和插件，Arclight 是值得优先对比的方案，发布与源码信息都在其代码仓库中公开。
