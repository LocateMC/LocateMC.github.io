Bukkit 是定义 Minecraft Java 版服务端插件 API 的开源项目。虽然它本身的官方服务端已停止发布新版本，但其 API 设计深刻影响了 Spigot、Paper 等后续所有主流核心，堪称插件生态的事实标准基础。

它今天更重要的身份是「源头」：CraftBukkit、Spigot、Paper 一脉相承，绝大多数服务端插件也都基于 Bukkit API 开发；SpigotMC 上还保留着完善的插件开发资料，是理解这套体系的最佳入口。

需要注意的是，Bukkit 已不适合作为新服务器的运行核心，但对想理清插件生态脉络、或准备开发插件的读者来说，它的参考价值依然很高。
