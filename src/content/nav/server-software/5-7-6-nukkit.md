Nukkit 是一款使用 Java 语言编写的基岩版服务器软件，由 CloudburstMC 社区维护。凭借 Java 生态的开发便利性，它成了许多基岩版服主的入门选择。

沿用 Java 的开发习惯，意味着熟悉 Java 的人几乎不用重新学习就能上手，插件生态也自成体系；项目由 CloudburstMC 组织长期维护，可靠性有社区背书；部署上跨平台运行、配置直观，上手成本很低。

它的定位可以概括为「基岩版里最容易被 Java 开发者接受的一个」，官方网站是获取程序与文档的入口。
