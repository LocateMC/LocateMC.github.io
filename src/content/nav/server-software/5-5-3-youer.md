Youer 是 MohistMC 团队（Mohist 混合端的作者）推出的 NeoForge 混合服务端，目标是让同一台服务器既能加载 NeoForge 模组，又能运行 Bukkit/Spigot/Paper/PurPur 生态的插件，并持续完善 Paper/PurPur API 的兼容层。

它在兼容面上的投入比较具体：

- **NeoForge 模组支持**：接入 NeoForge 体系，可以加载现代 Forge 模组；
- **Paper/PurPur API**：实现 Paper 与 PurPur API，兼容面比传统混合端更广，目前仍在持续跟进；
- **插件生态兼容与 Remapping**：整合 Bukkit/CraftBukkit/Spigot 插件接口，并参考 Arclight 的思路完成插件桥接与重映射。

文档由团队自己维护，英文与中文版本齐备，中文资料的更新也比较及时。对想用 NeoForge 模组、又不愿放弃 Paper/PurPur 插件生态的服主来说，它是少数对症的方案；发布与源码都在其代码仓库中公开。
