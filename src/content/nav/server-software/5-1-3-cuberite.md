Cuberite 是一款使用 C++ 编写的 Minecraft 服务器软件，与官方服务端完全独立，不依赖 Java。凭借轻量高效的架构，它在小内存设备与嵌入式场景中表现得相当出色。

原生实现带来了启动快、占用低的优势，低配主机乃至树莓派一类设备都能跑得动；跨平台能力覆盖 Windows、Linux、macOS 以及移动端等多种环境；扩展方式则走 Lua 插件路线，内置的插件生态活跃，也便于二次开发。

如果你的目标是在低资源环境下开一个轻量服务器，或者希望用 Lua 而不是 Java 来写插件，它会是一个值得考虑的选择；下载与文档都可以从官方网站进入。
