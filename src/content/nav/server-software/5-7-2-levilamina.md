LeviLamina 是专为基岩版官方服务端 BDS 设计的插件加载器，允许开发者使用 C++、C#、JavaScript、Lua 等多种语言编写插件，是基岩版服务器模组生态的核心基础设施。

它的一大特点是一套 API 支持多种开发语言，不同技术背景的开发者都能上手；在国内基岩版开服圈子里，它已是主流选择，社区活跃；官方还提供详尽的开发文档与示例。

也就是说，只要服务器基于 BDS 并且需要插件能力，LeviLamina 基本是绕不开的一环，官方网站是获取程序与查阅文档的入口。
