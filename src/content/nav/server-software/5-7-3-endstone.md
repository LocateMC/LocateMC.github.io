Endstone 是一款用 Python 语言编写的基岩版服务器软件，核心目标是在 Python 中重新实现 Bukkit API，让 Java 版生态里那些成熟插件有机会运行在基岩版服务器上。

它把服务端生态直接开放给 Python 开发者，写插件不再必须掌握 C++ 或 PHP；同时以兼容 Bukkit 为方向，尝试打通 Java 版与基岩版之间的插件壁垒——当然，这仍是一个需要持续投入的目标。项目本身开源，开发在 GitHub 上保持活跃。

对熟悉 Python、又想折腾基岩版服务端的开发者来说，它提供了一个少见的入口。
