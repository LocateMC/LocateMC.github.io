Fabric 是新一代轻量级 Minecraft 模组加载框架，以模块化设计和极快的版本更新速度著称；配合 Fabric API，它已经长成一个庞大而活跃的现代模组生态，服务端与客户端模组都能加载。

它的启动开销小、加载结构简洁，新游戏版本发布后跟进也非常快，大量现代模组与整合包都以 Fabric 为开发平台。

追求「第一时间玩到新版本 + 轻量启动」的玩家，通常会在 Fabric 与 NeoForge 之间做取舍：前者胜在轻与快，后者胜在传统大型模组更多。官方网站是最直接的下载入口。
