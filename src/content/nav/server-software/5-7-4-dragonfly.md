Dragonfly 是一款使用 Go 语言从零编写的基岩版服务器软件，以现代化的异步架构和原生性能著称，为 Go 开发者提供了完整的服务端开发入口。

Go 的原生并发模型让它在性能上表现优异，整体架构也完全按新思路设计，而不是在旧代码上缝补；项目在 GitHub 上开源且免费，社区持续贡献代码。

如果团队本身就在 Go 技术栈上，或者看重新架构带来的性能与可维护性，它值得一看。官方网站与代码仓库是获取它的直接途径。
