Paper 是目前最流行的 Minecraft Java 版服务端核心，由 Spigot 分支而来，通过数百项性能优化补丁显著提升服务器的并发能力与稳定性，同时完整保留对 Bukkit/Spigot 插件的兼容。

它的优势集中在三点：针对区块加载、实体运算等热点做了深度优化，因而成了大型服务器的事实标准；插件层面不仅完整支持 Spigot 生态，还提供能力更强的 Paper API；开发团队长期活跃，版本更新与主流 Minecraft 版本保持同步。

对于绝大多数想开 Java 版服务器的服主，Paper 都是默认起点——性能与生态都已足够成熟，下载与文档直接在官方网站获取即可。
