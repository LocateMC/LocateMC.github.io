Minecraft Forge 是最经典的 Java 版模组加载框架，支持把成百上千个模组同时加载在服务端与客户端；多年积累的庞大模组生态，使它至今仍是众多模组服务器的基础选择。

它的优势一半来自体量：CurseForge、Modrinth 上海量模组都把 Forge 当作传统运行平台，科技、魔法类等老牌大型模组也大多基于它开发。另一半来自版本策略——新版本的开发重心已逐步移交 NeoForged，老版本则仍由 Forge 继续维护，旧版本的整合包依然有人照看。

如果服务器依赖某些只支持 Forge 的老模组，选它基本没有替代方案；反之在新版本建服时，不妨先确认目标模组是否已转向 NeoForged。下载与文档都在官方网站。
