BDS（Bedrock Dedicated Server）是微软官方发布的基岩版专用服务器程序，提供 Windows 与 Linux 两个平台版本，是搭建原版基岩版服务器最直接的选择。

它由官方出品，与游戏版本同步更新，原版体验有保障；本身就是跨平台的，部署环境选择比较自由；虽然原版不带插件机制，但可以通过 LeviLamina 这类加载器扩展出插件支持。

因此它的典型用法有两种：想开纯净原版基岩服，直接用它即可；想要插件生态，则以它为底座再叠一层加载器。官方下载页是获取程序最可靠的入口。
