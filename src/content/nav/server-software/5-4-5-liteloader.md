LiteLoader 是面向 Minecraft Java 版的轻量级模组加载器，主打「轻量、透明」：不修改原版代码就能加载模组，早期以众多实用小功能模组著称，是 1.12 及更早版本上的经典选择。

它对原版的侵入性极小，适合搭配轻量实用型模组，也因此在老版本时代积累了大量小功能；局限同样明显——主要活跃于较老的游戏版本，新版本上已很难作为主力加载器。

所以它的现实用途更偏向翻老整合包，或维护仍在旧版本运行的老服务器。如果确实有这类需求，官方网站仍是获取它的入口。
