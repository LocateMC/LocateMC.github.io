Spigot 是 Minecraft Java 版最经典的服务端核心之一，在 CraftBukkit 基础上加入了性能优化，同时运营着全球最大的插件资源社区 SpigotMC。

它的分量主要来自生态：海量免费插件资源集中在同一个社区，绝大多数服务端插件都基于 Spigot/Bukkit API 开发，兼容性因此相当稳定；配合完善的 Wiki 与教程，新手开服时遇到问题也容易找到答案。

如今性能上已有 Paper 等更激进的继任者，但作为插件生态的源头与稳定的经典选择，Spigot 依然值得了解——下载服务端与浏览插件都在同一个官方社区完成。
