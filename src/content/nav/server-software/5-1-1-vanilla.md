Vanilla 指 Mojang 官方发布的 Minecraft Java 版服务器程序（Minecraft Server），不含任何第三方修改与优化，忠实还原游戏本体的全部特性与机制。

它与游戏客户端同步更新，因此总能呈现最纯粹的游戏体验；也正因未经改动，它成为一切第三方服务端核心的对照标准——想知道某个核心偏离原版多少，最终都要回到它身上比对。代价是原版默认不带插件与模组支持，要扩展功能得自己接上 Bukkit、Forge 这类生态。

所以它适合两类人：想验证原版机制、或只需要一个干净服务端的玩家，可以直接取用官方程序；而准备开插件服的服主，通常把它当作起点与基准，而非最终选择。
