PowerNukkitX 是基于 Nukkit 的增强分支，由国内社区主导开发，持续跟进最新的基岩版版本，并在其基础上加入大量新特性与性能优化。

它最实用的一点是版本跟进快，新版基岩协议往往能较早得到支持；因为是 Java 系实现，插件也用 Java 编写，对熟悉 Java 的服主很友好；背后的国内开发者与用户社区比较活跃，沟通与求助都更方便。

如果开的是基岩版服务器、又希望用 Java 写插件，它在国内环境里是比较顺手的选项，官方网站可获取下载与文档。
