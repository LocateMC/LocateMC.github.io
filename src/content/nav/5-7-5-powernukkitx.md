PowerNukkitX 是基于 Nukkit 的增强分支，由国内社区主导开发，持续跟进最新基岩版版本，并加入大量新特性与性能优化，是国内 Java 系基岩版服务器的热门选择。

### 特点

- **版本跟进快**：快速支持新版基岩协议
- **Java 生态**：基于 Java 开发，插件以 Java 编写
- **社区驱动**：国内活跃的开发者与用户社区

官方网站：https://powernukkitx.com/
