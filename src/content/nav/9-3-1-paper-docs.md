PaperMC Documentation 是广受欢迎的高性能 Minecraft 服务器软件 **Paper**（一个 Spigot 的分支）的官方技术文档网站。它是一个综合性的知识库，旨在服务于两大核心用户群体：**服务器管理员**和**插件开发者**。对于前者，它提供了详尽的服务器配置、优化和管理指南；对于后者，它则提供了 Paper 独有 API 的开发教程和参考。

### 发展历程

Paper 最初源于一个名为 "PaperSpigot" 的项目，其目标是集合各种性能优化补丁，以解决原版和 Spigot 服务器在大型社区中普遍存在的性能瓶颈。随着项目的不断发展，它逐渐从一个“补丁集”演变成了一个拥有自己独立 API 和开发团队的、更完善的分支 (Fork)，并最终更名为 "Paper"。这个官方文档站点的建立，标志着 Paper 项目的成熟，它取代了过去散落在论坛和 GitHub 上的零散信息，为整个社区提供了一个统一的、权威的知识来源。

### 社区生态位

PaperMC 在 Minecraft 社区中扮演着“**高性能服务器的事实标准与官方手册**”这一无可替代的关键角色。
1.  **性能的标杆**：对于绝大多数追求高性能、高稳定性的公开服务器（尤其是拥有大量玩家的服务器）来说，使用 Paper 或其分支（如 Purpur）已成为业界的“黄金标准”。这份文档则是配置和驾驭这一高性能平台的“官方说明书”。
2.  **Bukkit/Spigot API 的超集**：Paper 在兼容所有 Spigot 插件的基础上，提供了大量独有的、性能更优或功能更强大的 API。这份文档是插件开发者学习和利用这些高级 API、编写出更高质量插件的唯一权威指南。
3.  **服务器管理员与开发者的共同语言**：该文档是连接服务器管理员和插件开发者之间最重要的桥梁。管理员通过它来理解和配置服务器的各项性能开关，而开发者则通过它来编写能与这些配置良好协作的插件，共同确保了服务器生态的健康与高效。
