BBSPK（新兴我的世界论坛晋级赛）是一份由社区玩家共同维护的《我的世界》简体中文论坛生态普查页，本身并非论坛，而是旁观论坛兴衰的「观察哨」。2024 年 1 月 22 日 MCBBS 关站后，大量新兴论坛接连涌现，这份页面便以「论坛 PK 晋级赛」的叙事包装逐年盘点目前可见的中文 MC 论坛与资源站：逐条记录站点域名、建站日期、运行状态、ICP 与网安备案情况、运营备注，并附上 B 站动态、微信公众号文章、网页存档等佐证资料作为参考资料。截至 2026 年 9 月，页面共收录 81 个站点——正常 33、故障 2、淘汰 46（其中停摆 29、已关闭 17），另设「表演赛选手」栏目收录 26 条围绕 MCBBS 的衍生内容与纪念页面。

### 内容结构
站点分三个板块：

- **晋级赛选手**：正式的论坛收录名单，每条含名称、域名、建站时间、最后更新时间、ICP 备案（已备案 / 未备案 / 备案中）、网安备案、备注与参考资料；运行状态以 `up`（正常运行）、`failure`（存在故障或访问困难）、`down`（停摆）、`close`（已宣布关闭）、`unknow`（未知）五档标注。名单涵盖 MCBBS、最MC、MineBBS、苦力怕论坛、九域资源社区、暮光方块论坛、红石中继站，以及 MCBBS 2nd / 3rd / 4th 等一批沿用旧名的后继者。
- **表演赛选手**：收录以 MCBBS 为主题的二创内容、纪念站与网络迷因，如「回来吧 MCBBS」「复活牢坛」「MCBBS 114514th」「坛破山河在，坟头草木深」等，性质更接近文献而非站点目录。
- **统计信息**：访问计数、贡献者名单与 GitHub 星星增长曲线。

页面顶部另有两组实时计时器，分别记录「距离晋级赛开始」与「距离第二阶段开始」的时长。全部条目按统一字段罗列，参考资料较多的条目折叠展示。

### 数据与贡献
全部数据存放在仓库的 `res/data/forums.js` 中，分为 `db_forums`（晋级赛）与 `db_forums_ex`（表演赛）两个数组，字段结构清晰、注释完备，改数据即等于更新站点。项目托管于 GitHub `LYOfficial/BBSPK`（★213、fork 101，2024-02-27 建仓），由 LYOfficial 与 sheep-realms 维护；任何人 Fork 后修改数据、向 `dev` 分支提交 PR 即可参与收录，页面内容以 CC BY-NC-SA 4.0 协议共享。

### 彩蛋与设计
页面藏了不少小细节：每天 19:00 至次日 6:00 自动切换夜间配色，4 月 1 日会换上愚人节专属 Logo；在页面上同时按住 `Z` + `X` 可触发「圣光爆发」动画，而「立即报名」旁那颗「发射」按钮，会在角落拉起红警式的「核彈攻擊 10:00」倒计时。站名与视觉沿用了《某魔法的禁书目录》标题字体的排版风格（「とある新兴の我の世界」），呼应它作为「旁观者」的立场。
