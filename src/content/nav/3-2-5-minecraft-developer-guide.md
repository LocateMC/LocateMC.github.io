《我的世界开发者中文指南》（Minecraft Developer Guide）是一个由社区贡献者共同编写、托管于 GitHub（Mouse0w0/MinecraftDeveloperGuide）并以 GitHub Pages 发布的**简体中文 Minecraft 开发一站式指南**。它的出现与 MCBBS 关站导致大量中文教程失效直接相关——项目方在页面上呼吁读者协助联系作者迁移教程，并欢迎通过 Issue 或 Q 群提交开发相关资源。全站内容以 CC BY-SA 4.0 协议共享，目标是为中文开发者提供从入门到进阶所需的教程、资料与类库索引，弥补中文开发文档的空白。

### 内容板块
站点按开发方向分块组织，目录几乎覆盖 Minecraft 开发的全部分支：
- **基础与通用**：Java 基础（入门书籍、JDK、设计模式）、提问的方法、常用网站与资源。
- **Java 版模组**：Forge、NeoForge、Fabric 各版本（1.7.10 至 1.21+）开发指南、MDK 配置、Mixin、渲染系统、世界生成、网络通信与模组迁移。
- **Java 版插件**：Bukkit/Spigot、BungeeCord、Sponge 的官方教程、API 文档、事件监听、NBT、ProtocolLib、自定义实体与配置数据库。
- **数据包（Data Pack）**：原版模组入门、数据包文档与生成工具。
- **启动器开发**：编写启动器教程及 C#/Java/Python 等多语言类库。
- **基岩版（Bedrock）**：服务端（LeviLamina、Endstone、PowerNukkitX 等）、Addons（行为包/资源包）、模组（Horizon、Amethyst）与网易基岩版。
- **着色器包**：图形学社区文档、OptiFine、OpenGL 学习资源。
- **过时资源**：LiteLoader、Nukkit、PocketMine 等历史内容整理。

### 社区生态位
在中文 Minecraft 开发生态里，这份指南占据「**社区共建的中文开发知识总入口**」这一独特生态位。与官方 / 单框架文档（如 Fabric Wiki、Forge Docs、Paper 文档）只覆盖自身技术栈不同，它是一个横向整合的"索引层"：把分散在英文 Wiki、官方文档、视频与各框架教程里的中文可用资源汇聚到一处，并在 MCBBS 退场后填补了中文开发教程的断层。对于想"先看清 Minecraft 开发到底有哪些方向、各自该看什么"的入门者，以及需要跨框架横向检索的开发者，它都是目前最系统、最新的中文起点站之一。
