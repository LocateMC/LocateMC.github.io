自定义合成配方（Crafting Generator）是一个功能非常专一的在线工具，作用是让数据包作者通过可视化的、类似游戏内工作台的界面来创建自定义合成配方。把物品拖放到合成格、设置好产物，它就会自动生成符合 Minecraft 数据包规范的 JSON 文件。

它由社区开发者 TheDestruc7i0n 创建。自 Minecraft 1.13 引入数据包系统后，一个非常普遍的痛点随之出现：手动编写用于定义合成配方的 JSON 文件不仅繁琐、重复性高，还极易因为一个逗号或括号的错误就让整个文件失效。该工具把这一过程完全图形化，显著提升了创作效率与准确性。

它在社区中扮演「数据包作者的厨房料理台」与「自定义合成的效率工具」：

- **极大地降低了门槛**：它是「想添加一个新合成公式」的创意与「实现它所需的复杂 JSON 代码」之间最直接的桥梁，让不熟悉 JSON 语法的玩家也能为自己的整合包或地图添加自定义合成；
- **从重复劳动中解放**：对需要添加大量配方的数据包作者而言，它把枯燥易错的手动编码换成几次点击，让人能专注在更有创造性的玩法设计上；
- **数据包生态的基石**：自定义合成是数据包最核心、最基础的功能之一，这个工具是支撑无数自定义地图、整合包与服务器玩法的重要基础设施。

只要你的创作涉及「让某样东西能被合成出来」，它几乎都是第一步。
