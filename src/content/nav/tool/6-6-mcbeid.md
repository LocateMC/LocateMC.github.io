MCBEID 是一个专门为 Minecraft 基岩版玩家与开发者设计的、功能全面的 ID 查询网站。它系统性地收录了基岩版中几乎所有类型的 ID——除了方块与物品，还涵盖实体、效果、附魔、生物群系乃至游戏规则（Gamerule）等，同时支持通过中英文名、命名空间 ID 等多种方式快速搜索，并提供清晰的分类筛选功能。

该网站由 ProjectXero 团队或个人开发者创建并维护。它的诞生是为了解决基岩版社区长期缺乏一个集中、准确且用户友好的 ID 查询数据库的问题：与 Java 版不同，基岩版的许多技术细节与 ID 信息较为分散，该工具通过系统化的数据整理与友好的前端界面把这些关键信息整合在一起，成为一个持续更新、服务于基岩版技术玩家的基础设施。

MCBEID 在社区中扮演「基岩版命令与附加包开发者的核心手册」，生态位相当明确：

- **填补基岩版空白**：相较于 Java 版成熟的生态，基岩版高质量、专业化的开发工具相对稀缺，它精准地补上了「ID 数据查询」这一基础而重要的环节；
- **服务核心玩家**：主要服务对象是基岩版的命令方块玩家、服务器服主以及附加包（Addon）开发者，准确的命名空间 ID、数据值与命令参数是他们进行创作和管理的必备信息；
- **提升开发效率**：把过去需要翻阅 Wiki、解包游戏文件甚至反复试错才能获得的信息，变成了触手可及的在线数据库，是推动基岩版技术社区发展的重要工具。

需要查任何一项基岩版 ID 时，它通常是最快的那一档选择。
