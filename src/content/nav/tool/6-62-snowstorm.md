Snowstorm 是专为 **Minecraft 基岩版粒子文件**（`.particle.json`）打造的可视化编辑器，由 Blockbench 的作者 **JannisX11** 开发。它同时以**网页应用**（`snowstorm.app`）和 **VS Code 扩展**两种形态提供：网页版打开即用、无需安装；扩展版会在资源包 `particles/` 目录下自动接管 `.particle.json` 文件，保存即生效。

### 核心能力

- **实时 3D 预览**：右侧为参数面板，改动任一数值即刻反映在预览场景中；用鼠标左/右键与滚轮即可在 3D 空间中自由观察，界面右下角实时显示 FPS 与当前粒子数。
- **Molang 表达式**：绝大多数数值字段都支持 Molang，可填静态数字，也能写表达式驱动动态行为；复杂表达式可在菜单下方独立的表达式栏中编辑。
- **Quick Setup 快速上手**：内置一组预设的**运动、时序与物理**配置，不熟悉参数体系的新手也能快速拼出一个可用的粒子。
- **曲线与颜色编辑**：提供曲线编辑器与颜色选择器，用于精调尺寸、颜色等随粒子生命周期的变化过程。
- **导入导出与代码视图**：通过 File 菜单导入导出粒子文件；切到 Code 标签页即可查看甚至直接改写生成的 JSON。若使用自定义贴图，需在侧栏的 Textures 分区单独加载。
- **内置示例**：附带若干示例文件，可直接打开参考或在其基础上修改。

### 两种形态

- **网页应用**：入口 `snowstorm.app`，零安装，适合初学者与单次调参；同时注册了 PWA manifest，可「安装」到桌面使用。
- **VS Code 扩展**：在 Marketplace 搜索 `JannisX11.snowstorm`，适合在工程内批量处理多个粒子文件，工作流程更快。

项目以 **GPL-3.0-or-later** 开源，基于 Vue 2 + three.js 构建，Molang 求值由 `molangjs` 承担；如需自建，`npm install` 后运行 `npm run watch` 即可本地起服务。

### 发展历程

Snowstorm 于 **2019 年 5 月**发布首个版本（`V1.0.0`，2019-05-10），初代即确立了「3D 预览 + 参数面板」的基本形态。2020 年底的 v2.2.1 加入 PWA 支持、曲线编辑器并重写菜单栏；2024 年初补上 Quick Setup 与贴图编辑；2024 年 11 月修复循环模式；2025 年 7 月的 v3.2.1 与 **v3.2.2（2025-10-18）** 持续打磨细节（如变量占位符栏的完善）。截至目前仓库累计 **237 stars**，迭代节奏稳定。

### 社区生态位

Snowstorm 在基岩版创作链中扮演「**粒子效果的可视化车间**」这一角色，与同作者的 Blockbench（模型与动画）以及官方文档体系共同构成完整的资源创作闭环：

1.  **把 JSON 变成看得见的东西**：粒子文件本质是一堆描述发射器、速率、生命周期与曲线的参数，手写几乎无法预判最终效果。Snowstorm 通过实时预览把「写参数」变成「调效果」，是这类工作流里最关键的一环。
2.  **被官方文档直接采用**：Microsoft Learn 的《Particle Effects》与《Snowstorm - Overview》教程均以它作为教学工具，并明确标注其由 JannisX11 开发、属于**社区第三方产品**（非 Mojang / Microsoft 官方提供，请自行斟酌使用）。
3.  **双形态覆盖不同人群**：网页版降低入门门槛，VS Code 扩展让专业资源包作者在工程内高效批量作业——同一套代码服务两类用户，这也是它长期保持活跃的原因之一。
