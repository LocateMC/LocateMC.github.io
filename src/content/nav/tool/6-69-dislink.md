Dislink 工具集是开发者 DislinkSforza 做的 Minecraft 在线转换工具箱，十六款工具全部围绕「格式转换与创作素材生成」，以基岩版为主、多数同时兼顾 Java 版。最省心的一点是**所有处理都在浏览器本地完成**：文件不会上传服务器，免安装、免注册、无广告，打开网页就能用。

按用途分成六组：

- **音乐转换（2 款）**：MIDI 转基岩版 mcfunction 音乐包，支持音色映射与多音轨合并；另有把 MIDI 转成 BDX / mcstructure / mcpack 的转换器，可直接生成命令方块结构。
- **图片与视频创作（5 款）**：图片转 `setblock` 命令阵列（BE / JE 双版本）、文本转粒子 mcfunction、盲文字符画生成器（图片或视频转 Braille 字符画，带抖动与阈值调节）、地图画生成器（图片视频转方块结构，支持抖动开关与 Y 轴自适应居中）、彩色视频字符画生成器（§ 颜色代码配字符映射，输出到 actionbar）。
- **结构与格式转换（2 款）**：结构 3D 查看器可在线打开 mcstructure、litematic、schem、BDX、nbt、mca 与 mcworld 世界存档（Java 与基岩都吃），支持分层、漫游、LOD 与贴图；结构格式转换器把上述格式互相转换，另含 wsmr 与 MCEdit 旧版 schematic，并支持大结构与多区域文件。
- **命令与 mcfunction（2 款）**：mcfunction 转 BDX / mcstructure 结构文件（支持 CBD 扩展）、计分板进度条 titleraw 命令生成器。
- **文本与 JSON 编辑（3 款）**：原始 JSON 文本编辑器带 rawtext 模板与实时预览；可视化编辑器用「拖放积木」的方式拼装 rawtext；网易违禁词检测按正则匹配并高亮命中组。
- **存档与数据（2 款）**：NBT 可视化编辑器以树形增删改节点、支持撤销重做，覆盖 gzip / zlib、未压缩大端与基岩版小端，并可导出多种格式；网易存档加解密支持文件夹、zip 与 mcworld 上传，自动识别加密状态后导出。

在这个生态里它的位置比较特别：Minecraft Tools、Gamer Geeks、Astroworld Tools 这些工具集主要面向 Java 版玩家与服主的日常需求，而 Dislink 明显更偏**基岩版创作者**——mcfunction 音乐包、mcstructure 与 BDX 结构、网易版存档处理，都是中文基岩创作圈里高频却一直缺趁手在线工具的场景；尤其网易存档加解密与违禁词检测这两项，同类站点里几乎找不到替代。

站内带搜索框与标签筛选，工具按上述六组陈列；页面底部留了 QQ 群、B 站与 GitHub 三个入口，作者以社群方式答疑并放出新工具抢先体验。
