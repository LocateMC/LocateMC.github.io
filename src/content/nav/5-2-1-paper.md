Paper 是当下最流行的 Minecraft Java 版服务端核心，源自 Spigot 的分支，通过数百项性能优化补丁显著提升服务器并发能力与稳定性，同时保持对 Bukkit/Spigot 插件的完整兼容。

### 特点

- **高性能**：针对区块加载、实体运算等热点深度优化，是大型服务器的事实标准
- **生态兼容**：完整支持 Spigot 插件，并提供更强大的 Paper API
- **持续维护**：活跃的开发团队与版本更新，支持主流 Minecraft 版本
