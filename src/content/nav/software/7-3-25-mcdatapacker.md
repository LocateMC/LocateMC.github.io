MCDatapacker 是一款用 C++ 与 Qt 写的 Minecraft 数据包桌面编辑器，把「新建或打开数据包 → 管理文件 → 编辑 → 查错」整条链路收进一个原生程序里。它完整支持 1.15 – 1.20.4 的数据包，对 1.20.6 – 1.21.4 提供部分支持；Windows（作者在 Windows 7 与 Windows 11 上实测过）与 Linux（AppImage）都能跑，Windows 版下载解压后直接运行 `MCDatapacker.exe` 即可，无需安装。界面为英文。

程序的重心是那个代码编辑器：

- **函数与 JSON 语法检查**：编辑 `.mcfunction` 与 JSON 文件时实时标出问题，状态栏直接给出当前文件的问题计数；
- **函数文件智能补全**：命令、目标选择器、命名空间 ID 等都有补全提示，也支持用户自定义命令语法；
- **Ctrl + 点击跳转**：点光标下的命名空间 ID 即可跳到对应文件；
- **多标签编辑与文件树**：左侧树形视图负责新建、改名、删除文件，编辑区按标签页组织。

除纯文本编辑外它还内嵌了几个侧栏编辑器，这部分明显受社区工具启发（作者在 README 里致谢了 thedestruc7i0n 的配方生成器与 misode 的生成器）：一个是**可视化合成配方编辑器**，另外是谓词、战利品表与物品修饰器编辑器。

其余实用功能包括数据包的文件与命令用量统计、**原始 JSON 文本（text component）可视化编辑器**、**俯视视角的进度树查看器**、在程序内直接预览 `pack.png` 一类图片，以及内嵌原版数据包文件（不含结构文件）供离线查阅。Windows 下会自动跟随系统切换暗色模式，程序也以占用存储与内存小为卖点。

需要如实说明的是**它的维护节奏已经慢下来了**：最新版 v0.11.0 发布于 2025 年 3 月，仓库最后一次提交在 2025 年 5 月；发版在 2023 年比较密集，之后间隔逐渐拉长，而声明支持的版本上限停在 1.21.4，尚未跟进更新的 Minecraft 版本。项目以 Apache-2.0 协议开源，作者 IoeCmcomc 把开发中的版本也一并放在 Releases 页，并提醒程序「可能包含错误，使用需自担风险」。下载请认准项目的 Releases 页。
