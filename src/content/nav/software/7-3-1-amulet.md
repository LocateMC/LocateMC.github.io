Amulet 是一款功能强大的开源 Minecraft 地图编辑器，支持 Windows、macOS 与 Linux。它最核心的特性是能够无缝读取、编辑并保存 **Java 版和基岩版**两种世界格式，甚至支持在两者之间进行转换。它提供了全 3D 的编辑视图，允许用户进行精细的方块操作、区域选择、复制粘贴以及导入导出建筑蓝图。

Amulet 的诞生是为了填补传奇地图编辑器 MCEdit 在现代 Minecraft 版本中留下的空白。随着 MCEdit 停止更新，社区迫切需要一款能够支持新世界格式（特别是基岩版）的现代工具。Amulet 从零开始构建，采用了更现代的技术架构，并从一开始就将跨版本支持作为核心目标；凭借强大的功能和开源的特性，它迅速被社区认可，成为新一代地图编辑器的标准。

在生态里，Amulet 是“MCEdit 的现代精神续作”与“连接两大游戏版本的桥梁”。它的独特价值在于打破了 Java 版和基岩版之间的壁垒，是目前唯一能成熟地对两个平台的世界进行深度编辑和互通的工具。对于大型地图创作者、需要进行版本迁移的服务器服主，以及所有希望进行超大型建筑或地形改造的玩家来说，它都是一款不可或缺的、强大的“创世”工具。
