MCAPPX 是一个专注于提供 Minecraft 基岩版 (Windows) 官方客户端安装包的资源网站。它为 Windows 10/11 用户收录了海量的历史版本，提供 `.appx` 或 `.msixbundle` 格式的离线安装文件，方便玩家进行版本管理和安装。

它要解决的是 Windows 平台玩家在版本控制上的痛点：微软商店默认只提供最新版本的下载，给需要连接特定版本服务器、或因特殊原因需要使用旧版的用户带来了不便。MCAPPX 通过系统性地存档并提供各版本的离线安装包填补了这一空白，成为一个高度专业化的工具站。

在生态里，MCAPPX 是“基岩版 Windows 客户端的时光机”。它是服务于 Windows 平台基岩版玩家的专属版本库，与服务 Java 版的 MCVersions、服务安卓版的 BBK 共同构成了完整的版本控制工具矩阵。对于需要进行版本回溯或离线安装的 Windows 玩家来说，这里是唯一也最可靠的资源获取渠道。
