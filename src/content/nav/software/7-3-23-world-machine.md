World Machine 是一款面向技术美术的专业级**程序化地形生成软件**。它不以笔刷雕刻地形，而是用节点图（Node Graph）搭出一条运算管线：从分形噪声出发，让侵蚀、河流、遮罩等一百多个器件逐级加工，再输出高度图（Heightfield）、流痕与磨损遮罩、材质覆盖图以及 PBR 贴图，交给 Unity、Unreal、Blender 等引擎负责渲染。它的招牌能力是**侵蚀模拟**——水流自行冲沟、切脊、把沉积物留在该留的地方，因此能在极大的尺度上快速得到可信的地貌。整套流程是非破坏性的：改动上游任意一个参数，下游会自动重算，任何一段器件网络还能封装成宏（Macro）复用到下一个项目。

### 发展历程

World Machine 自 2005 年诞生，理念始终是「仿真，而非雕刻」，每一个版本都以一座山峰命名。2008 年的 World Machine 2 让它成为此后十余年 AAA 项目地形生成的常客。2025 年的 Hurricane Ridge 重写了仿真内核，高分辨率下的侵蚀运算提速至多 100 倍；2026 年的 **Dragontail Peak** 又进一步支持悬崖倒挂与洞穴（VDM 体素位移），重建了界面与宏系统，并首次提供原生 macOS 与 Linux 支持。

### 在 Minecraft 创作中的位置

需要说明的是，World Machine **并非 Minecraft 专用工具**，官网也没有针对 Minecraft 做任何适配，它服务的对象是游戏与影视的环境美术。不过在 Minecraft 地图创作的流程里，它可以充当上游的「地形源头」：先用它生成并导出高度图与遮罩，再经由 WorldPainter 一类工具导入游戏，就能得到远比原生算法壮阔的世界骨架。它还支持分块构建（Tiled Builds），可产出远超内存限制的整片大陆，并按引擎就绪的分块形式写出——对大型生存服、史诗级冒险地图的前期地形来说，这是相当实用的一环。
