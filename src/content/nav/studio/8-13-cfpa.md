CFPA（CFPA Team，GitHub 组织 CFPAOrg）是一个开源、非盈利的 Minecraft 模组汉化组织，cfpa.site 是它的项目门户。组织由社区译者以 GitHub 协作方式运转，所产出的汉化全部公开发行、供所有玩家免费使用，翻译内容以「知识共享署名—非商业性使用—相同方式共享 4.0」协议授权。

核心产物是汉化资源包 **Minecraft-Mod-Language-Package**：项目从 CurseForge 中选取 1.12 / 1.16 / 1.18 / 1.19 版本合计上千款模组，基本覆盖了玩家日常所需的主流内容，译者提交的语言文件经审核后由系统自动处理、打包成资源包并上传云端。配套的 **I18nUpdateMod3** 是游戏内的自动汉化更新模组，玩家装好后启动游戏即可自动拉取最新版汉化，不必手动下载资源包。组织还维护 **Glossary** 英中术语库（统一译名，避免同一术语在不同模组间出现译法分歧）、**TransRules** 翻译规范，以及面向 1.10.2 / 1.12.2 主流整合包的手册本地化仓库。

网站本身承担「项目门户 + 入门引导」的角色：想参与翻译的玩家可从参与入口了解语言文件的结构与机制、查阅翻译规范、再通过 GitHub 提交 Pull Request 或工单系统送审，站上还提供配套视频教程与译者名单。门槛设定得相当友好——官方明说模组翻译不是英语考级，对英语水平要求并不很高，更需要的是耐心与细心；零散的模组翻译、模组搬运工或服主提供的语言文件同样接收，经审核后一并发布。对于只想「玩到中文模组」的普通玩家，它几乎是装整合包后的必备基建；对有志于汉化的新人来说，这里也是国内最成熟的一条入门路径。
