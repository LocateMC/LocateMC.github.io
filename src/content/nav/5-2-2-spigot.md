Spigot 是 Minecraft Java 版最经典的服务端核心之一，在 CraftBukkit 基础上加入性能优化，并运营着全球最大的插件资源社区 SpigotMC。

### 特点

- **插件生态**：海量免费插件资源，论坛社区活跃
- **兼容稳定**：绝大多数服务端插件基于 Spigot/Bukkit API 开发
- **社区支持**：完善的 Wiki 与教程，适合新手开服

下载服务端与浏览插件请访问：https://www.spigotmc.org/
