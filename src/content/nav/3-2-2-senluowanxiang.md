森罗万象（ResGuide）是由知名纹理包作者 **SQwatermark** 编写并维护的**中文 Minecraft Java 版资源包制作指南**。它面向"想自己做资源包"的玩家与创作者，系统讲解资源包从格式规范到高级技巧的制作全流程。作者在开篇即点明定位：这份指南只负责讲清"如何制作资源包"的技术与规范，不负责传授美术能力——审美需要靠读者自己在实践中打磨，这让内容边界清晰、直奔技术主题。

### 覆盖内容
- **原版资源包技术细节**：完整的资源包结构与文件规范，以及如何在原版机制内实现各种视觉效果。
- **OptiFine 资源包专题**：作为重点扩充方向，深入解读 OptiFine 专有特性（如 CTM 连接纹理、动态材质、动态 GUI 等），文中大量章节配有中文社区作者的实战案例（如 CTM 案例、原版动态材质案例、动态 GUI 案例）。
- **配套章节**：附有「提问须知」（引导读者高效求助）与「OptiFine 与 Forge / Fabric 兼容性」说明，作者坦言 OptiFine 高版本 Bug 较多，遇到问题要学会自己排查。

### 社区生态位
在中文 Minecraft 社区里，森罗万象占据着一个稀缺的位置：**面向中文使用者的、体系化的资源包技术文档**。英文世界有各类零散英文教程与官方文档，而中文社区长期缺少一份把"原版 + OptiFine"资源包技术细节掰开揉碎的系统性指南，森罗万象正是为填补这一空白而生。它以 MCBBS 论坛（作者与共同维护者 Xiao2）与 QQ 群（纹理资源官方群）为讨论阵地，读者提问、作者答疑，形成持续迭代的活文档。对想钻研纹理与模型技术的玩家来说，它是中文语境下绕不开的起步与进阶参考。
