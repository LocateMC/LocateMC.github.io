Chunkoid 是一个专为安卓端打造的 Minecraft 世界转换器，也是全网首个把"存档跨版本转换"搬进手机的开源工具，社区常称它为"Chunker 手机版"。它完全开源免费（GPL v3），让玩家无需电脑即可完成基岩版与 Java 版的存档双向互转、1.8.8 至 1.21 及 26.x 等多版本升降级、JE-BE 材质包双向转换，甚至支持网易版加密存档的解密；转换全程日志透明，所有结果统一收纳管理，支持文件夹、.zip、.mcworld 与资源包等多种输入格式，一键即可导出使用。

### 发展历程
Chunkoid 诞生于独立开发者 Dozener 的一个朴素念头：为什么转存档非得打开电脑？过去玩家想在 Java 与基岩之间搬运世界，只能依赖 Chunker 网页端或桌面工具，移动端一片空白。Dozener 以 HiveGames 开源的 chunker-cli 为核心引擎，将整套转换能力打包进安卓端，并针对手机场景持续打磨——加入网易版存档解密、后台唤醒锁、低运存防闪退模式与无效维度裁剪等特性。项目走红后，原作者将其无偿捐赠移交至 DICECAN (EncoreTeam) 团队继续维护演进，从 v1.2.0 一路迭代到 v2.0.0，社区交流群与 GitHub 同步保持活跃更新。

### 社区生态位
Chunkoid 在生态中扮演着 **"手机端的存档摆渡人"** 与 **"双版本玩家的移动桥梁"** 的角色。它把过去必须依赖电脑与网页工具才能完成的活，压缩进一部手机里：基岩玩家想体验 Java 端的地图与光影，Java 玩家想把世界搬去基岩联机，网易版存档想转成国际版继续游玩——这些曾经的"劝退难题"，如今在 App 里点几下就能完成。凭借"完全开源免费 + 专为移动端设计"的双重优势，它填补了移动端世界转换工具的长期空白，成为手机党在跨版本、跨平台路上最省心的中转站。
