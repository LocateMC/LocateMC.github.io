ICMods 是一个功能专一的在线平台，其核心作用是作为 Inner Core 模组的中央存储库。Inner Core 是一个早期在 Minecraft 携带版（PE）/ 基岩版上实现的、功能极其强大的第三方模组加载器，它让移动端也能运行类似 Java 版的复杂模组；ICMods 则是所有为 Inner Core 开发的模组的「官方」发布、分享和下载中心。

在 Minecraft 基岩版官方市场（Marketplace）和附加包（Addon）功能尚不成熟的年代，以 Inner Core 为代表的第三方加载器，为追求深度 modding 体验的移动端玩家打开了一扇大门。为了解决 Inner Core 模组分散、难以寻找和分享的问题，ICMods 平台应运而生：它为开发者提供了一个上传和管理自己作品的后台，也为玩家提供了一个集中、安全、便捷的模组下载渠道，成为了整个 Inner Core 生态系统的核心基础设施。它在当时的角色可以概括为三点：

- **生态的核心**：在它的鼎盛时期，ICMods 就是基岩版（携带版）的 CurseForge，是连接 Inner Core 模组开发者和海量玩家的唯一桥梁，几乎所有知名的 IC 模组都在此发布；
- **赋能移动端**：它让移动端的玩家和开发者能在手机上体验到工业、林业、建筑等大型模组的乐趣，这在当时是革命性的；
- **历史的见证**：随着官方附加包（Addon）功能的完善和 Inner Core 项目的逐渐沉寂，ICMods 的活跃度已不如前，但它所存档的大量模组，共同见证了基岩版社区在追求高度可玩性和自定义的道路上，所迸发出的惊人创造力和技术实力。

对于今天仍在使用 Inner Core 的玩家来说，它依然是寻找可用模组的主要去处，也是这段移动端 modding 历史最完整的记录者。
