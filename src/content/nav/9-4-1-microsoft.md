Minecraft Creator Learning Portal 是由 **微软 (Microsoft)** 官方维护和发布的、面向所有 **Minecraft 基岩版 (Bedrock Edition)** 创作者的**权威学习与文档中心**。它为希望创建自定义游戏内容的开发者，提供了一整套从入门到精通的、结构化的学习路径和技术参考。其内容全面覆盖了基岩版创作的方方面面，包括创建附加包 (Add-Ons)、使用脚本 API (Scripting API)、制作官方市场 (Marketplace) 内容等。

### 发展历程

该学习门户的建立，是微软和 Mojang 在推动基岩版创作者生态系统专业化、标准化进程中的一个关键里程碑。随着基岩版加入了越来越强大的自定义功能（如脚本 API），社区迫切需要一份由官方背书的、准确、可靠且持续更新的技术文档。于是，微软将其整合进了自己成熟的 `learn.microsoft.com` 技术文档体系中，旨在为 Minecraft 创作者提供与其他专业开发者（如 Azure 或 Windows 开发者）同等级别的、高质量的文档体验。

### 社区生态位

该门户在 Minecraft 社区中扮演着“**基岩版创作的唯一真理来源 (Single Source of Truth)**”和“**官方标准与最佳实践的发布台**”这一无可替代的权威角色。
1.  **官方的“圣经”**：对于所有基岩版的开发者——无论是个人爱好者还是专业的市场合作伙伴——这里都是他们**必须学习和参考**的起点和终点。它是所有技术问题的最终权威答案。
2.  **生态的基石**：它是整个基岩版附加包和脚本 API 生态得以健康、有序发展的基石。所有希望自己的作品能稳定运行、并在未来版本中保持兼容的开发者，都必须严格遵循这份文档中定义的规范。
3.  **从“爱好者”到“开发者”的桥梁**：通过提供专业、系统的教程和示例，该门户极大地降低了玩家向开发者转变的门槛，是微软培养和赋能新一代基岩版内容创作者的核心阵地。
