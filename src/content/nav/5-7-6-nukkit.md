Nukkit 是一款使用 Java 语言编写的基岩版服务器软件，由 CloudburstMC 社区维护，凭借 Java 生态的开发便利性，成为许多基岩版服主的入门选择。

### 特点

- **Java 开发**：沿用 Java 开发习惯，插件生态自成体系
- **开源社区**：由 CloudburstMC 组织长期维护
- **部署简单**：跨平台运行，配置直观
